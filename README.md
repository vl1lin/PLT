# PLT — планшет ПГИ

Веб-приложение для работы с данными промыслово-геофизических исследований скважин:
окна кривых по глубине, интервалы и их группы, сводка по интервалу, комментарии,
линии и заливки.

**Приложение:** https://vl1lin.github.io/PLT/

## Возможности

- Загрузка LAS 1.2/2.0 (кнопка «LAS» или перетаскивание файлов на планшет), кодировки UTF-8 и Windows-1251.
- Окна кривых: создать, скрыть, удалить (с возвратом), переставить, переименовать; кривые —
  скрыть, копировать в другое или новое окно, убрать, изменить шкалу и цвет.
- Масштаб: Ctrl+колесо у курсора, кнопки −/+, 1:200…1:2000, «Весь», лупа, «Предыдущий вид».
- Перемещение: протяжка мышью, средняя кнопка, колесо, навигатор слева.
- Интервалы: два щелчка (кровля, подошва), группы с цветами, интервалы во всех окнах или в одном,
  сводка по видимым кривым на кровле и подошве, комментарии.
- Линии по двум точкам и заливка между линиями.
- Проект сохраняется одним файлом *.plt.json (Ctrl+S) вместе с кривыми.

## Запуск на своём компьютере (Windows, PowerShell)

1. Установить Node.js 22 LTS или новее:

   ```powershell
   winget install OpenJS.NodeJS.LTS
   ```

2. Установить зависимости и запустить сервер разработки:

   ```powershell
   npm install
   npm run dev
   ```

   Откроется адрес вида http://localhost:5173 — изменения в коде видны сразу.

3. Перед коммитом проверить код:

   ```powershell
   npm run check
   ```

## Публикация

Каждый пуш в ветку `main` запускает GitHub Actions: проверки, сборку и публикацию
на GitHub Pages. Pull request в `main` проходит только проверки.

## Редактор

Zed поддерживает TypeScript из коробки. Для подсветки ошибок линтера можно
установить расширение oxc (Extensions → «oxc»).
