# PLT — веб-приложение для данных ПГИ

Замена интерфейса Камертона (Lint) для работы с данными промыслово-геофизических
исследований скважин: планшет с окнами кривых по глубине, интервалы, комментарии,
рисование линий и заливок. Интерфейс на русском. Хостинг — GitHub Pages
(https://vl1lin.github.io/PLT/), сборка и деплой — GitHub Actions при пуше в `main`.

## Стек

- Vite 8 + React 19 + TypeScript (строгий режим, `tsc -b` без ошибок)
- zustand — состояние, zod — валидация данных проекта (аналог pydantic)
- oxlint — линтер (аналог ruff), vitest — тесты
- Кривые рисуются на Canvas 2D, интерфейс — обычный DOM

## Команды

```
npm install        # установка зависимостей
npm run dev        # локальный сервер разработки
npm run check      # линтер + типы + тесты (то же, что в CI)
npm run build      # сборка в dist/
```

Перед каждым коммитом `npm run check` должен проходить без ошибок и предупреждений.

## Структура

```
src/
  domain/   чистая логика и типы: model.ts (схемы zod), viewport.ts (масштаб/перемещение)
  data/     источники данных: демо-набор, позже парсеры LAS/CSV
  state/    store.ts — глобальное состояние и действия
  ui/       React-компоненты экрана
  render/   отрисовка кривых на Canvas (этап 1)
  styles/   CSS-токены и раскладка
```

Зависимости направлены строго вниз: `ui → state → domain`, `data → domain`.
`domain` не импортирует React и ничего из `ui`/`state`.

## Правила кода

- Полная типизация: без `any`, `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`.
- Код проходит `oxlint --deny-warnings` и `tsc -b`.
- Данные, которые сохраняются или приходят извне, — через схемы zod.
- В начале каждого модуля — комментарий со схемой взаимодействия объектов.
- У каждой экспортируемой функции — TSDoc: параметры, результат, что делает.
- Единицы — СИ; глубины в метрах по стволу (MD), в именах суффикс `M` (`topM`, `spanM`).
  Неоднозначные величины — с единицей в имени или в TSDoc.
- Чистые функции домена покрываются тестами `*.test.ts` рядом с файлом.
- Не усложнять; принцип SOLID — там, где появляется настоящая иерархия.
- Рефакторить только ту часть, которую требует задача.

## План реализации

0. Инфраструктура: каркас, линтер, тесты, CI/CD на GitHub Pages — готово.
1. Отрисовка кривых на Canvas, шкала MD, ствол; масштаб (Ctrl+колесо, кнопки, пресеты 1:N,
   лупа, «предыдущий вид»), перемещение (протяжка, средняя кнопка, колесо, навигатор).
2. Управление окнами и кривыми: создать/скрыть/удалить/переставить окно, добавить/скрыть/
   копировать/убрать кривую.
3. Интервалы: выделение, группы, интервалы в отдельных окнах, сводка по видимым кривым,
   комментарии.
4. Рисование: линии и заливка между линиями.
5. Загрузка данных (формат уточняется: LAS 2.0 / CSV), сохранение и загрузка проекта (JSON).
